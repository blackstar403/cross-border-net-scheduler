# SCN-01 受控处理策略

## 动作族 ACT-01：保持出口的连接重建或配置重载

首版唯一候选动作族是：**在不改变当前出口选择、节点、线路、IP 或全局网络设置的前提下，重建当前已选出口的连接会话，或重新加载该出口的既有配置。**

它针对“本地客户端/代理会话暂态异常”的候选层级，不针对平台封禁、认证、限频、目标服务故障或物理链路问题。它不等同于换节点、健康检查自动回退、重启系统网络或清除浏览器 Cookie。

## 能力合同

执行适配器在实际动作前必须返回以下字段；任何字段缺失都不能执行。

| 字段 | 要求 |
|---|---|
| `action_id` | 固定标识，如 `reconnect_current_egress` 或 `reload_current_profile` |
| `available` | 当前环境明确支持该动作，而非仅有文档或按钮 |
| `preserves_egress` | 实测或可比较状态证明动作前后出口选择不变 |
| `scope` | 仅当前客户端/当前 Profile，不能影响全局设备网络 |
| `preconditions` | 运行状态、权限、目标 Profile 和当前出口状态 |
| `rollback` | 动作失败后的恢复步骤及其可执行性 |
| `before_state` | 脱敏的已选出口标识与连接状态 |
| `after_state` | 与 `before_state` 同口径的状态 |

`preserves_egress` 不能只由“没有调用换节点 API”推断，必须比较动作前后的已选出口标识或等价状态。若环境无法读取该状态，则动作不可执行。

## 资格闸门

| 检查 | 通过条件 | 不通过后的结果 |
|---|---|---|
| 任务边界 | `SCN-01` 有目标、症状、时间窗和 `preserve_egress=true` | 回到 `needs_input` |
| 证据关联 | 至少有支持本地/代理暂态异常的证据，且没有更强非网络反证 | `handoff`，不重连 |
| 适配器可用 | `available=true` 且读取当前状态成功 | 只读诊断 + 转交 |
| 出口保护 | `preserves_egress=true` 且可比较动作前后状态 | 拒绝动作 |
| 影响范围 | `scope` 仅限当前客户端/Profile | 拒绝动作 |
| 回退 | 有明确回退，或动作本身可证明无持久变更 | 拒绝动作 |
| 用户确认 | 用户看见影响范围、出口约束和回退后确认 | 不执行 |

## 执行与复测

1. 保存 `before_state` 与处理前任务探针结果。
2. 展示动作名称、影响范围、出口保持声明、回退方法和风险，取得确认。
3. 调用适配器一次，不自动重试。
4. 保存工具返回、`after_state` 和出口比较结果。
5. 使用原目标、原成功判据和同一出口约束复测。
6. 分别写入动作状态和业务状态：
   - 动作成功 + 业务恢复：`resolved`。
   - 动作成功 + 业务未恢复：`unresolved`，给出转交摘要。
   - 动作失败：尝试声明的回退；随后为 `unresolved` 或 `handoff`。
   - 出口比较失败或无法判断：不判定恢复，转 `handoff`。

## 当前验证状态

这个动作族是**真实环境尚未实测的设计候选**。仓库已用模拟适配器实现资格闸门、确认、动作和同任务复测状态机，结果见 [../test/report.md](../test/report.md)，但当前没有可调用的真实适配器或真实业务 Profile，故真实环境的 `available`、`preserves_egress`、`rollback` 都不能设为真。实际闭环必须另行完成适配器验证。

## 无动作与转交

以下情况直接进入 `REQ-ACT-03`：目标响应显示认证/限频/平台错误，缺少任务证据，适配器未运行，权限不足，出口保持无法验证，或用户未确认。转交摘要只记录任务、时间、脱敏状态、证据、未执行原因、已尝试动作及复测结果。
