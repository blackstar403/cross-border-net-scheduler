# 风险与停止条件

| 风险 | 当前事实 | 设计应对 | 不能声称 |
|---|---|---|---|
| 动作无法保持出口 | 尚无适配器实测 | 资格闸门要求前后状态比较；失败则不执行 | 已能安全重连或修复 |
| 页面异常不是网络问题 | 公开案例存在授权、限频、平台等反例 | 分层诊断和 `handoff` | 所有后台失败都可网络修复 |
| 探针不能代表登录后任务 | 当前无真实业务 Profile | 同目标复测；模拟标识 | 已恢复真实店铺业务 |
| 现有工具已覆盖流程 | AdsPower/Mihomo 等已有诊断或动作能力 | 做同题对照，记录缺口 | AI 或 MCP 自身构成差异 |
| 秘密泄露 | 代理和 Cookie 可能包含敏感信息 | 最小读取、脱敏和默认只读 | 可无边界读取现有工具 |
| 物理与平台边界 | 延迟、出口、平台风控不可由控制面消除 | 明确限制和服务商转交 | 全球加速、保证不封号 |

停止或缩小条件：无法证明一个动作保持出口且可恢复；探针无法形成可比较任务结果；现有工具同题已同样省事；或主要问题始终属于平台/授权而非可处理的本地状态。满足任一条件时，首版只能定位为诊断与转交原型。
