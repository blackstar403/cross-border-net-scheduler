# 方案设计

**本模块回答：** 如何接入已有资源，完成诊断、受控处理和恢复验证；AI 是否有用。

**钱潮杯完成：** 一页架构、选定场景的诊断和动作条件、复测口径、平台能力与失败分支。

| 计划文档 | 内容 |
|---|---|
| `architecture.md` | 观测/诊断、控制面、平台执行适配、结果视图；数据面不自建 |
| `scheduling.md` | 受控动作、业务约束、恢复与无动作分支；与 REQ 编号对应 |
| `ai.md` | 质量分类与策略，不接聊天大模型充数 |
| `data.md` | 店铺/出口/探测/场次；无真实密钥 |
| `risks.md` | 物理上限、误限速、代理失效、合规 |
