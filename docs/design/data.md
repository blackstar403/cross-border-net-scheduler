# 最小数据模型

| 对象 | 关键字段 | 说明 |
|---|---|---|
| `Task` | ID、目标别名、症状、时间窗、环境、`preserve_egress` | 不保存真实店铺 ID 或完整 URL 查询参数 |
| `ProbeResult` | 时间、成功判据、实际结果、来源、环境摘要 | 区分模拟、实测、用户描述和工具声明 |
| `Evidence` | 层级、支持/反证、置信程度、未覆盖项 | 不能把猜测存为已确认原因 |
| `AdapterCapability` | 动作、可用性、范围、出口保持、回退 | 仅适配器声明并经验证后可标可用 |
| `ActionRecord` | 确认、前后状态摘要、执行结果、回退结果 | 不存密钥、Cookie 或代理凭据 |
| `Verification` | 处理前后探针、业务结论、无法判断原因 | 动作状态与业务状态分开 |
| `Handoff` | 脱敏任务摘要、证据、未执行原因、责任方 | 可导出给工具、网络或平台支持 |

记录中所有出口信息使用本地稳定别名或脱敏哈希。模型和日志接收最小化字段；原始响应、完整网络配置和身份数据默认不落库。
