# 竞品分层

按**卖的是哪一层**分，不按品牌热度排。点名只用于举例，不做未核实的口碑排名。

| 层 | 代表形态 | 真正交付 | 对中小卖家的硬短板 | 证据 |
|---|---|---|---|---|
| 个人加速器 | 轻蜂、蓝鲸等 | 白名单应用加速 | 货不对版、不是作业网、信任差 | E06 L1 |
| 跨境 SD-WAN / 电商专线 | OSDWAN、悦播、各类盒子 | 出国连通 + 有的给静态 IP | 共享冒充独享、不按店铺/应用调度、质量不可见 | E05 L2 |
| 运营商 IPLC/IEPL | 电信联通点对点 | 物理独享 | 贵、慢、中小买不起 | E10 L2 |
| 云加速 | 阿里云 GA、腾讯 GAAP/EdgeOne | 海外用户访问源站 / 动态加速 | 账单和配置是给网工的；方向常反（买家访问 ≠ 卖家办公） | E07 L1 |
| 全球 CDN | Cloudflare | 欧美独立站 | 不管卖家办公网；套在 Shopify 上官方不支持 | E09 L1 |
| 指纹浏览器 + 代理 | AdsPower 等 + 住宅代理 | 环境隔离 | 不管链路质量；和网络供应商互相甩锅 | E02 L2 |

## 空档（仍是假设，用核验 C 打）

没有一层同时提供：

1. 店铺级出口不串  
2. 开播时让路  
3. 用后台秒数 / 同步失败 / 本场降质来交代，而不是 Mbps  

这就是控制面。若访谈里卖家说「我已经用盒子 + 指纹浏览器，两店 IP 不同，直播也不和上传一起开」，空档对那个人不存在。

## 不要写成的句子

- 「我们全面优于 OSDWAN」
- 「Cloudflare 做不了中国所以我们做」——那是另一张战场
- 「对标阿里云 GA」——客群和方向都不同
