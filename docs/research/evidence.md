## E01 国内访问 Seller Central 慢、超时

| | |
|---|---|
| 主张 | 中国大陆直连 Amazon Seller Central 常高延迟、丢包、页面超时；高峰更明显。 |
| 等级 | **L2**（现象被多处重复；本仓库尚未本机复现） |
| 支持 | 中文卖家技术帖普遍给出 ping/hosts 排查；Amazon 卖家论坛有「超时、要用某种网络才能打开」类讨论。GreatFire 类检测称 sellercentral.amazon.com **并非完全墙死**，更像质量差而非打不开。 |
| 反证/限制 | 未封死 ≠ 能干活。论坛帖质量参差；加速器文会夸大「6 秒变 1.8 秒」。 |
| 你怎么验 | 核验 A：晚高峰 ping/mtr + 浏览器打开时间，对比手机热点。 |
| 对产品 | 若为真：后台打开时间作为看板指标成立。不为真：不要把「打开后台」当第一痛点。 |

## E02 平台用 IP 做关联/风控信号之一

| | |
|---|---|
| 主张 | Amazon 等会把登录 IP、地理一致性、数据中心/共享出口当作风险信号；同出口多店更危险。 |
| 等级 | **L2** 机制；**L4** 幅度（封号比例不可信） |
| 支持 | 卖家社区长期把「一店一 IP、别和同事共用 Wi‑Fi」当操作纪律；Amazon 对注册期代理更敏感。 |
| 反证/限制 | IP 只是多信号之一（设备、支付、行为）。无法保证「独立 IP = 不封号」。行业文里的 23%、40%、60% 无公开样本，**作废，不引用**。 |
| 你怎么验 | 核验 B + 问卖家核验 C 第 2 问。不要用自己的店去「试关联」。 |
| 对产品 | 出口绑定是可选场景；两个 IP 不同仅是网络测量结果，不能证明需求、独立带宽或通过风控。 |

## E03 同办公室 Wi‑Fi / 同一宽带是串店的常见现场

| | |
|---|---|
| 主张 | 中小团队多人、多店、多平台共用一个公网出口。 |
| 等级 | **L2** 现场常识；**L3** 具体惨案金额 |
| 支持 | 防关联教程几乎都从「别共用一个 Wi‑Fi」讲起，说明现场普遍。 |
| 反证/限制 | 知乎「5 店全封、2 万刀押金」是专栏故事，当作 L3。 |
| 你怎么验 | 核验 B；访谈问现在几个人几店几条出口。 |
| 对产品 | 店铺隔离的用户故事成立与否，取决于你问到的团队是不是这样办公。 |

## E04 直播卡顿的关键是抖动/丢包和开播瞬间，不只是标称 Mbps

| | |
|---|---|
| 主张 | TikTok 等开播时测网并可能锁定传输行为；1% 量级丢包就会在观众侧卡；上行被其他程序抢会放大问题。 |
| 等级 | **L2**「卡顿伤害直播」；**L3**「锁 TCP / 100Mbps 只用 20–30」的机制细节（来自服务商技术文，未独立复现） |
| 支持 | 直播从业者普遍强调稳定上行和有线；专线营销文详细写了开播测速。 |
| 反证/限制 | 未接 Live Studio 实测前，不要把「锁 TCP」写成已证实的产品原理。带宽需求数字（720p 8Mbps 等）是经验区间。 |
| 你怎么验 | 开播时同时拷大文件上传，看是否掉帧；有专线则对比「仅直播」vs「直播+上传」。 |
| 对产品 | 直播优先（让路）即使机制细节部分错，只要争抢为真就仍值得做。机制写进设计时标假设。 |

## E05 中小卖家买「专线」经常买到共享出口，高峰仍掉

| | |
|---|---|
| 主张 | 低价跨境加速/SD-WAN 用共享带宽和共享 IP 池；晚高峰掉速；测速时间与直播时间不一致。 |
| 等级 | **L2** 结构合理；**L3** 具体品牌差评 |
| 支持 | 与 SME SD-WAN 低客单、高支持成本一致（见 E08）：共享是保毛利的办法。避坑文反复警告「假独享」。 |
| 反证/限制 | OSDWAN/悦播等公开差评少，评测站不可独立引用。 |
| 你怎么验 | 核验 B 对「独享」套餐；晚高峰 vs 下午对照测速；问卖家月费和是否仍卡。 |
| 对产品 | 解释「为什么不跟他们拼管子」；不点名攻击未核实的品牌。 |

## E06 入门加速器货不对版（应用级 ≠ 出海作业网）

| | |
|---|---|
| 主张 | 轻蜂等按「全球加速」售卖，实际是白名单应用加速；消费保大量虚假宣传/退款投诉。 |
| 等级 | **L1** 投诉存在且官方 FAQ 自承应用级；**L2** 代表中小卖家入门路径 |
| 支持 | 消费保品牌页投诉聚合；官网 FAQ 写明不是全网代理。 |
| 反证/限制 | 投诉样本有偏（只有不满的人去投诉）。不能外推到所有加速器违法，只能说明品类信任差。 |
| 你怎么验 | 打开其 FAQ 与广告截图对照；不必购买。 |
| 对产品 | 新产品必须用业务指标自证，不能靠「专线」话术。 |

## E07 云全球加速对中小卖家：效果可能好，账单和配置不匹配

| | |
|---|---|
| 主张 | 阿里云 GA 按量：实例创建即收实例费；CU + CDT 分账；跨境流量贵且难用资源包抵扣。 |
| 等级 | **L1** 计费规则（官方文档） |
| 支持 | [阿里云 GA 按量付费](https://help.aliyun.com/zh/ga/pay-by-data-transfer-1/)：实例费约 0.137 元/小时；CU 约 0.386 元/CU/小时（按处理数据量）；精品跨境约 6.4 元/GB。文档写明跨境/跨地域流量无 GA 资源包抵扣。 |
| 反证/限制 | 目录价会变；企业可谈折扣。V2EX「太贵」是用户感受 L2。 |
| 你怎么验 | 用官方计算器按「晚高峰几 GB 跨境」估一笔，看是否远超卖家月网费。 |
| 对产品 | 大厂不做这个客群的硬证据之一：不是做不出加速，是卖不成这个价。 |

## E08 SME SD-WAN 客单价撑不起企业级交付

| | |
|---|---|
| 主张 | 中小企业 SD-WAN 单客户收入远低于大企业，必须靠标准化和规模；否则支持成本吃掉利润。 |
| 等级 | **L2**（分析机构公开摘要，全文付费未见） |
| 支持 | Analysys Mason《SD-WAN for SMEs》公开论述：SME 站点多、ARPU 低，升级可低至约 EUR 10–100/站点/月量级，需低触点。 |
| 反证/限制 | 未读全文 PDF，不能引用其内部数字当精确 ARPU。中国跨境卖家客单是另一市场。 |
| 你怎么验 | 问三家服务商：5M「独享」含几个公网 IP、是否共享底池、售后是否 7×24、月费。 |
| 对产品 | 「大厂不做控制面」的商业解释；不是技术做不到。 |

## E09 Shopify 再套 Cloudflare 代理：官方不支持，结账敏感

| | |
|---|---|
| 主张 | Shopify 不支持在店铺前再套 Cloudflare 橙云；可能干扰 SSL、机器人检测、结账。 |
| 等级 | **L1** |
| 支持 | [Shopify 域名排障](https://help.shopify.com/en/manual/domains/troubleshoot-issues-with-domains) 明文不支持 Cloudflare proxy（含 O2O）。Cloudflare 自己有 O2O 指南，但 Shopify 仍视为不受支持。 |
| 反证/限制 | 仍有店这么跑。这证明的是「越加速越慢」的一种机制，**不是卖家办公网问题**。 |
| 你怎么验 | 看独立站后台 Settings → Domains 是否有 Cloudflare 警告。 |
| 对产品 | 明确 **OUT**：不做独立站买家加速。避免把两个问题合成一个。 |

## E10 国际出口与最后一公里是物理上限

| | |
|---|---|
| 主张 | 大陆国际出口容量有限，晚高峰拥塞；中美有光速下限；卖家侧家宽决定 overlay 下限。 |
| 等级 | **L2** 结构（电信常识）；具体丢包百分比视线路而定 |
| 支持 | 跨境网络排障文、运营商国际带宽定价远高于国内骨干。 |
| 反证/限制 | 不同城市、不同 ISP 差异大。没有海缆容量的一手数据。 |
| 你怎么验 | 核验 A 的高峰/闲时对照。 |
| 对产品 | 方案禁止承诺「打破延迟下限」；调度是分配稀缺，不是创造带宽。 |

## E11 ERP 同步超时经常被当成软件问题

| | |
|---|---|
| 主张 | 积加等 ERP 文档出现连接超时类错误；国内到平台 API 不稳时，库存/订单会偏。 |
| 等级 | **L2** 文档存在该类错误；**L4** 「多数是网络」的比例 |
| 支持 | 厂商帮助中心有 timeout / 无响应类说明。 |
| 反证/限制 | 授权过期、平台限频、数据量同样导致不同步。 |
| 你怎么验 | 访谈问同步失败时有没有同时后台也慢；失败是否集中在晚高峰。 |
| 对产品 | 看板「同步失败次数」有意义；不要声称能修 ERP。 |
