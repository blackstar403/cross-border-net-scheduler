# 首版用户

## 目标角色

首版服务对象是使用已有宽带、代理或指纹浏览器，没有专职网工的跨境电商店长或运营。此人能描述正在执行的后台任务，知道该任务平时是否可用，并有权查看当前网络工具的非敏感状态。

这是一项待验证的目标用户假设，不代表已经访谈、招募或取得真实卖家使用反馈。

## 触发任务

用户正在访问一个明确的经营后台页面，例如订单、广告或帮助页面，当前无法正常打开或完成加载。用户希望先判断问题发生在哪一层，并明确要求保持当前店铺出口，不接受为了排障而静默切换节点、线路或 IP。

首版不接受“网络不好”“亚马逊用不了”这类未澄清描述直接触发处理。系统必须先取得目标页面、失败表现、发生时间和正常对照。

## 用户目标

1. 知道受影响的是哪个具体后台任务，而不是只看到延迟或带宽。
2. 看到支持诊断结论的证据、未覆盖范围和不确定性。
3. 仅在动作保持业务约束、权限明确且可以恢复时决定是否执行。
4. 用同一页面任务复测，并知道已恢复、未恢复或无法判断。
5. 无法处理时获得一份可交给工具厂商、网络服务商或平台支持的脱敏摘要。

## 使用前提

- 用户提供一个允许验证的目标 URL 或测试页面，不要求系统读取账号密码、Cookie、订单或支付信息。
- 已有网络工具允许读取必要的非敏感状态；读取失败也必须作为可见结果。
- 用户能确认“保持当前出口”约束，并在需要写操作时进行明确确认。
- 没有真实店铺测试环境时，可以使用可复现的模拟页面，但必须标明模拟，不能称为用户实测。
