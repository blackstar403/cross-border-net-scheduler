# SCN-01 测试计划

## 环境与证据口径

首轮测试使用本地模拟目标和模拟适配器，覆盖状态机和安全闸门；所有结果标记为模拟。后续适配器实测必须单列环境、版本、目标、出口保护比较和实际结果，不能与模拟汇总为真实恢复率。

| 用例 | 覆盖需求 | 前提与步骤 | 期望结果 | 当前状态 |
|---|---|---|---|---|
| TC-01 输入不足 | REQ-OBS-01 | 只输入“后台打不开” | 缺少目标和症状；零动作 | 待实现 |
| TC-02 正常对照 | REQ-OBS-01, REQ-OBS-03, REQ-VERIFY-01 | 完整任务 + 正常模拟目标 | 记录基线；不执行修复；结果为未复现 | 待实现 |
| TC-03 状态读取分支 | REQ-OBS-02, NFR-SEC-01, NFR-SAFE-02 | 模拟适配器返回成功、未运行、权限不足、读取失败 | 四种状态分别可见；输出无秘密 | 待实现 |
| TC-04 网络候选诊断 | REQ-OBS-03, REQ-DIAG-01, REQ-DIAG-02 | 模拟连接/代理暂态错误和支持证据 | 输出候选、反证、置信程度和未覆盖项 | 待实现 |

## 通过规则

- 所有用例先在模拟环境通过，作为实现逻辑证据。
- `TC-09` 不得被用作真实平台恢复证据。
- 在真实适配器环境中，至少重复 `TC-03`、`TC-07`、`TC-08`、`TC-10`，并对候选动作补充前后出口状态比较，才可将动作标为实测。
- 真实业务页面只有在明确授权且不读取秘密时才能复测；否则报告“未验证”，不得替换为导航成功。
